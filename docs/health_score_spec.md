# 건강 점수 계산 기준 명세서

## 개요

뿌지직 앱의 건강 점수는 사용자의 배변, 수분, 식사, 운동 기록을 종합적으로 분석하여 **100점 만점**으로 계산됩니다.

---

## 점수 구성

```
총점 100점 = 배변 상태(30) + 배변 규칙성(25) + 수분 섭취(20) + 배변 편안함(15) + 배변 빈도(10)
```

---

## 1. 배변 상태 (30점)

### 평가 기준
최근 7일간의 배변 기록을 Bristol Stool Scale 기반으로 평가

### 점수 산정

| Bristol Type | 상태 | 1회당 점수 | 설명 |
|-------------|------|-----------|------|
| Type 3-4 | 이상적 | 5점 | 바나나 모양, 부드러운 소시지 형태 | 
| Type 2, 5 | 보통 | 3점 | 약간 딱딱하거나 무른 변 |
| Type 1, 6-7 | 주의 필요 | 1점 | 변비(딱딱한 알갱이) 또는 설사 |

### 계산 방식
```
1. 최근 7일간 각 배변마다 위 점수 부여
2. 평균 점수 계산: (총 점수 / 배변 횟수)
3. 30점 만점으로 환산: 평균 점수 × 6
```

### 예시
- 7일간 6회 배변, 모두 Type 3-4
- 계산: (5점 × 6회) / 6회 = 5점 평균
- 결과: 5 × 6 = **30점 (만점)**

---

## 2. 배변 규칙성 (25점)

### 평가 기준
연속으로 배변을 기록한 일수 (매일 꾸준히 기록했는가?)

### 점수 산정

| 연속 기록 일수 | 점수 | 평가 |
|--------------|------|------|
| 7일 | 25점 | 완벽한 습관 |
| 6일 | 21점 | 훌륭함 |
| 5일 | 18점 | 양호 |
| 4일 | 14점 | 보통 |
| 3일 | 11점 | 노력 필요 |
| 2일 이하 | 5점 | 개선 필요 |

### 평가 이유
- 규칙적인 배변 습관은 장 건강의 핵심 지표
- 매일 비슷한 시간에 배변하는 것이 이상적

---

## 3. 수분 섭취 (20점)

### 평가 기준
오늘 수분 섭취량 대비 목표 달성률

### 점수 산정

| 달성률 | 점수 | 평가 |
|--------|------|------|
| 100% 이상 | 20점 | 목표 달성 |
| 80-99% | 16점 | 거의 달성 |
| 60-79% | 12점 | 보통 |
| 40-59% | 8점 | 부족 |
| 40% 미만 | 4점 | 매우 부족 |

### 계산 방식
```
달성률 = (오늘 수분 섭취량 / 목표 수분량) × 100
점수 = 달성률에 따른 점수표 적용
```

### 예시
- 목표: 2000ml
- 실제 섭취: 1600ml
- 달성률: 80%
- 결과: **16점**

### 중요성
- 수분 부족은 변비의 주요 원인
- 충분한 수분 섭취는 부드러운 배변에 필수적

---

## 4. 배변 편안함 (15점)

### 평가 기준
최근 7일간 배변 후 기분 평가

### 점수 산정

| 기분 평가 | 1회당 점수 | 설명 |
|----------|-----------|------|
| 좋음 | 5점 | 편안하고 개운함 |
| 보통 | 3점 | 무난함 |
| 불편함 | 1점 | 힘들거나 불편함 |

### 계산 방식
```
1. 최근 7일간 각 배변의 기분 점수 합산
2. 평균 계산: (총 점수 / 배변 횟수)
3. 15점 만점으로 환산: 평균 점수 × 3
```

### 예시
- 7일간 6회 배변, 5회 "좋음", 1회 "보통"
- 계산: (5×5 + 3×1) / 6 = 4.67점 평균
- 결과: 4.67 × 3 = **14점**

---

## 5. 배변 빈도 (10점)

### 평가 기준
최근 7일간 하루 평균 배변 횟수

### 점수 산정

| 평균 횟수 | 점수 | 평가 | 건강 상태 |
|----------|------|------|-----------|
| 1.0-2.0회 | 10점 | 이상적 | 정상 |
| 0.7-0.9회 | 8점 | 약간 적음 | 경미한 변비 가능성 |
| 2.1-3.0회 | 7점 | 약간 많음 | 주의 관찰 |
| 0.5회 이하 | 5점 | 매우 적음 | 변비 의심 |
| 3.0회 이상 | 5점 | 매우 많음 | 설사 의심 |

### 계산 방식
```
하루 평균 배변 횟수 = 최근 7일 총 배변 횟수 / 7
```

### 예시
- 7일간 총 8회 배변
- 평균: 8 / 7 = 1.14회/일
- 결과: **10점 (이상적)**

### 의학적 기준
- 건강한 성인: 하루 1~2회 또는 주 3~21회
- 하루 3회 이상 또는 주 3회 미만: 전문의 상담 권장

## 보조 기록의 영향

### 식사 기록 📝
**직접 점수 없음** (간접 영향만)

#### 영향 범위
- **배변 상태에 긍정적 영향**
  - 식이섬유 "높음" → Bristol Type 3-4 가능성 증가
  - 불규칙한 식사 → 배변 불규칙 가능성
  
#### 피드백 활용
- 식이섬유 섭취 낮음 → "채소와 과일을 더 드세요"
- 하루 3끼 규칙적 → "좋은 식습관이네요!"

### 운동 기록 💪
**직접 점수 없음** (간접 영향만)

#### 영향 범위
- **배변 규칙성에 긍정적 영향**
  - 주 3회 이상 운동 → 장 운동 활성화
  - 유산소 운동 → 배변 촉진
  
#### 피드백 활용
- 운동 부족 → "가벼운 산책이라도 해보세요"
- 규칙적 운동 → "운동으로 장 건강을 지키고 있어요!"

## 자동 피드백 시스템

### 피드백 생성 규칙

#### 1. 수분 섭취 부족 (< 12점)
```
💧 수분 섭취를 늘려보세요!
하루 2L를 목표로 물을 자주 마셔요.
```

#### 2. 배변 상태 불량 (< 20점)
```
🥗 식이섬유가 풍부한 음식을 드세요.
채소, 과일, 통곡물을 추천해요.
```

#### 3. 배변 규칙성 저조 (< 18점)
```
⏰ 매일 비슷한 시간에 배변하는 습관을 들여보세요.
아침 식사 후가 가장 좋아요.
```

#### 4. 배변 빈도 낮음 (< 7점, 평균 < 0.7회)
```
🚶 가벼운 운동과 수분 섭취를 늘려보세요.
걷기만으로도 장 운동이 활발해져요.
```

#### 5. 배변 빈도 높음 (< 7점, 평균 > 3회)
```
🏥 하루 3회 이상 계속된다면 전문의 상담을 권장해요.
식단 조절과 스트레스 관리가 필요할 수 있어요.
```

#### 6. 모든 항목 양호
```
🎉 훌륭합니다! 건강한 장 습관을 유지하고 있어요!
현재 생활 습관을 꾸준히 이어가세요.
```

### 복합 피드백
여러 항목이 낮을 경우 우선순위대로 최대 3개 표시

**우선순위:**
1. 수분 섭취 (가장 즉각적 개선 가능)
2. 배변 상태 (식이섬유 개선)
3. 배변 규칙성 (습관 개선)
4. 배변 빈도 (의학적 주의)
5. 배변 편안함 (종합적 평가)
